# 第一轮实战启动卡｜不用开发交易程序，也不需要真实资金

**状态：READY_NOT_EXECUTED。** 此操作卡写于 2026-11-10，是供下次真实观察使用的标准；文中所有操作尚未在真实 Froggy/GMGN 账号实测，不得标 DONE。目标：**1 份真实只读钱包报告＋至少 1 个可重查的交易事件＋未来首次可见信号的观察入口**。

## 首选路径 A：现成终端、零私钥

1. **寻找 1 个公开候选钱包**：打开 [GMGN Solana 发现页](https://gmgn.ai/discover/?chain=sol) 或官方 [Wallet Radar](https://docs.gmgn.ai/index/wallet-radar)。在实际屏幕记录当前筛选参数、观察时间与完整地址。若已可合法使用 Froggy，先用现有命令导出候选，保留批次。**不要购买付费服务作为第一步。**
2. **留存发现时点 T0**：记录“此刻首次看到”并注明时区；系统过去发生的 swap 只能作为历史，不能回填为观察者当时的可复制信号。把钱包按 WATCH、SKIP、UNKNOWN 初分；记录为何，不必从一开始就证明它赢利。
3. **打开真实钱包详情**：对地址选择一个 Mint，查看历史至少一笔真实 swap/transfer；尽量保存 explorer 签名、Slot/时间、Token owner、买/卖、报价资产净变化。仅有平台汇总标签则写 VENDOR_ONLY，切勿虚构某个 Token 的盈亏。
4. **按需调查邻居**：如看到 A→B Token Transfer，按 Mint 和账户 owner 查 B 是否真实 Swap 卖出；如果看不到接收 owner、B 交易或报价资产，按 EVENT_PARTIAL/UNKNOWN 结束。不要为了把图画完整而猜“同控”。
5. **建立只读关注**：如实际产品界面允许，加入 GMGN Wallet Tracker 或其他合法通知器，仅观察新买入、卖出、转 Token、SOL 转移；买卖提醒与转账提醒分别记录。记录真实收到时间 T_seen 和通知延迟，避免重复事件。
6. **判断可复制性而非发交易**：写一个不含未来信息的候选交易子集假说（例如“非首槽的某类买入只进入纸上实验”），附失效条件；不配置高滑点、不点击真实买卖/授权/签名。
7. **复核产物**：先确认至少一笔实际签名/真实来源、记录发现时间、标注缺失字段、留下可检查的 WATCH/UNKNOWN 判断；如果能持续观察，之后按 T0 后全部信号形成纸上统计。

## 备选路径 B：真实数据访问受阻也要有有效进展

- 选 [RU-003 真实公开来源记录](../research/RU-003-public-evidence.md) 的完整钱包或 Mint；用 GMGN/OKX/Solscan 等合法只读网页交叉核对。
- 只有市场价、排行榜和一个公开账户 URL，没有实际 swap 签名：只完成“来源验证与工具覆盖差异”，报告 EVENT_UNKNOWN，**不宣称真实资金链已经完成**。
- 如果 Froggy 无权限、GMGN 部分数据被限流、RPC 被封或历史不完整，转用第二个已有成熟工具查同一对象，并记录不同来源的数据契约；不无限重试接口，不转而开发一个未经验证的爬虫。
- 如果既有终端已提供跟单模拟，先确认它完全是 paper、能否输出原始报价/成交日志、费用和失败订单；不能确认隔离真实交易时不启用。

## 两种常见操作误区

**GMGN 的“批量导出”不等于交易流水导出**：官方 [Wallets Import Export](https://docs.gmgn.ai/index/wallets-import-export) 讲的是所关注地址及备注导入导出，不能把它当成每笔真实 Swap 的时间序列 CSV。要获取签名需另外查看钱包详情、Solscan/官方RPC或实际支持的导出来源。

**跟单的购买过滤不等于已保证退出**：OKX 俄语官方 [Trader Mode 文档](https://web3.okx.com/ru/help/how-do-i-use-the-okx-wallet-smart-account-for-copy-trading) 说明某些预算/亏损过滤只作用于买单，任务暂停也影响止盈止损状态；这部分先研究软件语义，别在真实资金上试验。
