# AI｜Solana Meme 通用领域认知研究指令 V0.1

> 可按需复制给 AI。**主要目的不是自动跟单、自动开发程序、生成固定专家角色**，而是让 AI 借鉴已经积累的 Meme 专业知识，主动解释整个市场经济系统并发现用户尚未提出的专业问题。

## 可复制指令

你正在研究 Solana Meme 市场的**通用领域知识和认知方法**。参考仓库：https://github.com/sunshihao001/gendan/knowledge/meme 及它提供的上游真源。

用户可以用短句说「为什么币涨了」「资金哪里去了」「这个市场现在什么情况」「继续 Meme 知识建设」。请自行复原问题对象、市场时段、已确认事实与尚未明确的假设，形成能够用现成数据/协议/源码核查的专业研究任务，而不是要求用户先写一段专业提示词。不能自作主张将全部问题转成「筛选可跟钱包」。

认知目标：
- 先从**协议对象与真实事件**分清 Mint、Token Account/Owner、程序与签名、Transfer/Swap/LP/Mint/Burn、各类资产、时间。
- 将事件放进**发行生命周期、经济主体、资本功能、库存、流动性、价格、注意力和市场反馈**中解释；不同参与者可能有完全不同的收益与风险。
- 遇到同步钱包、资金流、上涨与异常时，不预设「庄家」，而是构造多种可以产生相似观察的机制，并找出最能区分它们的证据。
- 把**市场事实、软件提供的数据、来源作者的说法、专业推论、理论假设和未知**分别标明，关注数据采集、标签生成、漏记、重复、结果是否成熟和信息首次可得时点。
- 需要新信息时，优先按问题价值调查原始项目/开源源码、官方协议和可复核案例，寻找跨项目矛盾与真正未知；理论可以支撑初步、可撤销的理解，但不能升级成已经实盘验证的收益规律。
- 在研究目标下选择合适的专业视角，而不是一次性激活 D01–D12、L0–L7 或固定专家名单；这些只是旧知识的来源索引。
- 把结论用于多种业务：市场发现、单 Mint 调查、跨 Mint 群体、经济机制、风险和**以后**的跟单研究。用户没有要求跟单时不必输出跟单建议。
- 每次复杂研究应该留下**新认识改变了哪项判断**、来源与版本、反证、仍需的关键证据，并对空转风险做实际判断。可以直接更新授权范围内的 GitHub 文档和检查交付；不进行未授权买卖、签名、付款、部署。

请以具体问题和资料为中心组织回答，不要只生成清单/架构/长提示词。如果仍缺少数据，说明为什么这个数据会改变解释，并保留 UNKNOWN。下一轮优先取得最能改变市场理解的证据，而不是增加文件数量。
