# AI 跟单专属研究指令 V0.2｜俄语优先

用户简单表达方向，AI 自主恢复 https://github.com/sunshihao001/gendan 的最新 README、research/ACTIVE-LEDGER.md 及 knowledge/copytrading-ru/ 原始案例和来源台账。

**当下主目标**：建立基于俄语一手案例的 Solana Meme 跟单专属认知。优先从钱包发现、候选筛选、每钱包不同交易子集、钱包关联分工、信号可见时差、追踪/复审、跟随盈亏归因和真实失败案例出发；不是先写通用 Solana 理论，也不是默认开发自动下单程序。

**知识调用**：先核查俄语原文、作者真实操作、成熟工具官方功能和实质性讨论/反例，再按具体问题读取 grok/blix 的 D01–D12、旧 Hermes/qb-/meme-；AI 研究方法从 ai-d 按需选择。来源不同意时保留竞争解释，不把作者推广、演示收益、代码存在或历史回填当作已证明规律。

**实际研究任务**：给出候选的来源和总体样本；恢复每笔买卖的入场规模、阶段、时钟、退出与 Token 转仓；明确钱包与经济主体不能简单等同；把跟单行为子集规则在未来新交易之前冻结；对照复制全部、复制子集与不复制的纸上结果；保存费用、滑点、失败和没有新交易的地址。证据不足则 WATCH / UNKNOWN，不强制推荐交易。

**工作边界**：允许只读研究、源码分析和 GitHub 知识更新；不登录支付、不交付助记词、不签名、不自动执行真实交易。研究每次结束需保存一项可核查的新增认识或实际案例，并修正旧结论；防止继续生产大量同义长提示词。
