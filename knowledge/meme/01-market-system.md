# 01｜Meme 市场作为动态经济系统：发行、角色、利益与注意力

> 内容类型：通用机制与条件性知识；不是交易策略、具体 Mint 的事实归因。关键继承：旧 Grok D02/D03/D05/D06/D07，Blix 的资金组织研究及 ai-d 跨学科问题研究。

## 从「币涨了」换成「哪些系统共同变化」

在给定发行平台和时刻，一枚 Meme 通常涉及：

**创建/发行配置 → 初始可交易场所和报价资产 → 早期交易与流动性变化 → 迁移/毕业/多池形成（视平台而定）→ 价格与注意力相互反馈 → 库存和风险重新分配 → 后续活跃/衰退/重启。**

这是一张**可能的状态关系图**，不是所有币必经的严格阶段：有些不迁移，有些多池并存，有些池反复被调整。做研究须先查实际程序、Mint、报价资产、池地址与发生时间，不凭走势图给它们贴「已毕业」「庄家吸筹」标签。

## 参与者不能按「散户 vs 庄家」二分

| 行为/权利主体 | 可能的目标和约束 | 可见线索 | 不能自动认定 |
| --- | --- | --- | --- |
| 发行者/创建者 | 发行成本、代币库存、可用权限、实际可能的 fee entitlement、声誉或其他收益 | mint/权限/发行账户/费收路径 | Dev 清仓=无利益；Dev 创建=全部库存控制人 |
| 早期买入者 | 价格优势、信息或执行优势；可能承受极多失败币 | 创建 Slot、买卖序列、失败 Mint 覆盖 | 早买=内幕/总会盈利 |
| 后来方向性买家 | 未来上涨预期、社群注意力、持仓风险 | swap 对价、余额、卖出 | 买家地址数=独立投资者人数 |
| LP/做市/套利参与者 | 赚费、管理库存/价差、承担无常损失及库存风险 | 流动性增加/减少、跨池 swap、LP 权利 | LP Vault 是某人可直接砸盘的普通钱包 |
| 交易服务和执行机器人 | 服务收入、执行排序、费预算、效率 | fee payer、指令模式、优先费、共享路由 | 同样机器人特征=同一决策人 |
| KOL/社群组织者 | 注意力、影响力、可能的商业合约 | 公开帖子/邀请、链上已验证转账 | 营销相关=发行者控盘；帖子=付费推广证明 |
| 平台/协议与验证者 | 平台费、协议收入、排序/服务经济 | 费率和真实收款结构 | 市场赚钱=Token 持币人赚钱 |
| 托管/交易所/桥/公共 Hub | 客户资产结算、撮合或转移服务 | 共享账户/集中路径 | 通过同一 Hub=一伙人 |

**五种关系应分开建模**：授权关系、执行关系、资本风险关系、决策关系、最终受益关系。一个钱包可连接多个主体，一个主体也可连接多个钱包；链上可见性对五者的覆盖差异很大。

## 为什么真实经济利益与表面价格方向可能相反？

同一枚币交易额突然增大：
- 对**方向性持币者**：不一定有获利；若后续买方不足，账面市值不可兑现。
- 对**LP/费收方**：若实际具备收取权，可能有手续费收入，同时也承担相应风险。
- 对**服务商**：客户付费使用工具可能产生收入，不必预测涨跌正确。
- 对**早期出售者**：新增买方和更深报价容量可能帮助其退出。
- 对**新入场者**：可能是在更高边际价格承担风险。

因此「成交量=利好所有人」是错误的问题表征。更深的问题是「谁支付哪一种成本？谁掌握哪一种权利？谁需要未来另一个参与者承担风险？」

**具体一手例证**：Pump.fun 2026-10-17 更新的费用说明中，交易成本按曲线/规范池、代币配对和市值层级变化，creator/protocol/LP 的分配与界面渠道相关；并非所有参与方都依赖代币上涨收益。政策是制度事实，**不能据此反推某个实际账户已获得收益**。来源：https://pump.fun/docs/fees 。

## 三条动态反馈链（机制假设，不是统计定律）

**链 A｜注意力—交易—可见性**
1. 叙事/KOL 提高关注度（有待具体数据证明是否真实提升）；
2. 终端将价格、成交、买家数排序展示，更多人注意到；
3. 用户交易会再次改变成交和平台排序，形成正反馈，也可能因风险/费用/逆转而中断。
**竞争解释**：原有真实利好、单个薄池小额冲击、关联换手、其他热门事件、平台收录机制。

**链 B｜库存—流动性—退出**
1. 早期账户获得 Token 库存；
2. Token 经转仓/托管/实际出售等不同方式流动；
3. 新买方/池报价资产不足时，账面上涨不代表可兑现；
4. 退出过程本身改变下一笔买卖的价格。
**竞争解释**：新增 LP、跨池套利、价格供给变化或程序行为可以改变同样的可见曲线。

**链 C｜市场结构—行为群体—新币**
1. 一批钱包在不同 Mint 里重复出现；
2. 可能是独立策略、共用平台/服务、共同资本组织或公众追逐同类主题；
3. 仅当资金/库存/时序与行为差异形成可靠增量，才进一步研究经济协调。
**竞争解释**：高活跃钱包本来就会出现在更多币里；需要活动量相近的对照。

## 用相互矛盾的观察推进认知

假设**价格上涨，净新增买家地址也上涨，但某个早期群体的 Token 持有量减少**。不能只挑其中一个说「吸筹」或「出货」，应同时问：

1. 买入地址是否独立？是否把 Token Account 当成了 owner？
2. 群体减少的是 Token 转出、swap 净卖出，还是 LP/托管迁移？
3. 当前价格对应哪个池，池储备/费用/深度是否变化？
4. 减少的库存是否进入新地址，新地址在何时实际成交？
5. 谁在承担新增价格风险，资金是否可追溯到新的独立购买方？
6. 只有哪个额外观察能够区分「新增真实承接」与「流动性/数据假象」？

**这就是专业认知**：先找到一条完整的经济机制，再寻求能推翻其解释的关键证据，而不是不断增加标签。
