# Solana Meme 通用领域认知｜知识入口 V0.1

> 当前定位：建立**先于跟单的通用市场认知**。这里研究市场本身的机制，不按某个软件的菜单、某个钱包标签或某个盈利策略来组织知识。2026-11-10 初版属于**对上游知识的选择性核查与综合**，不是全部历史材料已读完、已实证市场规律或 AI 已自动习得此知识。

## 一、认知主轴：不是「K线 + 钱包排行榜」

一个 Meme 市场同时是：
1. **协议与资产系统**：哪些 Token、账户、授权与池子存在；谁能在何时执行什么转移/交换。
2. **经济组织系统**：不同参与者使用本金、库存、流动性、费用权和注意力以实现不同目标。
3. **价格发现与流动性系统**：资金/库存、池储备、交易顺序、订单成本与退出容量共同制约价格和可实现财富。
4. **注意力与信息系统**：公开叙事、KOL传播、交易终端展示、社群传播与市场预期相互反馈；热度不等于独立真实需求。
5. **演化系统**：创建、曲线交易、迁移、不同池子的形成与变化、持仓再分配、旧参与者退出、新参与者进入。
6. **观测与研究系统**：平台只能看到其收录、解析、缓存、归类的部分事实；AI 解释并非额外原始市场数据。

研究必须把这六个系统**连接成一个动态过程**，又不能把观察到的联系直接冒充最终身份或因果关系。

## 四、通用市场问题的四种不同输出

- **机制理解**：在给定协议/经济条件下，为什么可能出现某种现象；允许理论互证的暂定结论。
- **对具体 Mint 的调查**：哪些资产与账户事件确实发生、是否覆盖完整；需要签名/Slot/来源。
- **群体比较与统计**：某类现象相对母样本是否更常见；需要选择、缺失、成熟度和对照。
- **预测/交易能力**：某次观测能否事前帮助决策；需要可得时间、可执行价格和样本外数据。

它们不互相替代；同一篇机制研究不必先完成交易回测，但也不能因此自称可盈利。

## 五、正确的来源继承方式

- **真源**：保留在 [grok 的 blix 知识目录](https://github.com/sunshihao001/grok/tree/blix/knowledge)、旧 Hermes / qb- / meme- 的原始仓库、[ai-d](https://github.com/sunshihao001/ai-d) 与必要的一手协议文档。
- **本仓库**：保留概念/机制/反例的**问题型综合**、通用认知方法与适用边界，指向原文件，不完整复制旧框架与全部正文。
- **阅读覆盖**：见 [来源与知识边界](SOURCES.md)。没读过的材料不得写成「完全继承」。官方协议、已读源码、文档推论、实跑结果是不同证据等级。
- **领域研究的价值锚点**：获得新的可解释差异、发现一个决定性未知、改变一个调查/决策方法，才值得扩张；只增文件、分类、长提示词不等于进步。

## 六、从市场通用认知延伸到跟单，但不逆向支配它

跟单将来只是一种场景，需要调用「钱包/群体角色 × 资金与库存 × 市场阶段 × 价格与执行 × 可观测时点 × 反证」的若干知识。新币发现、单 Mint 调查、跨 Mint 监控以及纯机制研究同样可以直接使用这套基础，**不先问能不能跟**。
