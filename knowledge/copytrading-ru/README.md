# 跟单领域的专属认知｜俄语来源优先

本入口不教一般的 Solana 经济学，而是研究：**如何从大量候选钱包中找到值得观察的具体行为，制定可提前写下的观察条件，排除历史绩效错觉，并通过后续信号检查是否真的可以复制。**

## 首份原始实践：Mark × Froggy

用户上传了俄中双语字幕，原视频：https://youtu.be/dxZqcCNAp3Y 。

按俄文字幕，作者一次从 Froggy Premium 取得约 215 个钱包。先看地址年龄、交易频率、是否狙击、实际每笔买入时市值、进场资金规模和卖出方式；初步保留 5 个准备复制的候选和 2 个仅作监控的地址。作者还把以前选出的钱包加入下一段调查：不同批次不得直接相除算“筛选成功率”。

第二轮他重新打开交易详情，发现一个初选钱包理由不清、交易结构不合意，于是剔除；对剩余地址按不同市值/买入金额提出不同过滤条件。再后面演示买卖、转账分别监控；十天左右回访钱包活跃情况与自己账户的跟单结果。**这是方法论最有价值的骨架，不是作者盈利被独立验证。**

详细研究：[视频逐段重建](01-mark-video-study.md)。

## 真正属于跟单的五类专业知识

| 专属对象 | 正确的问题 | 常见误判 |
| --- | --- | --- |
| 候选地址来源 | 哪个导出、什么时间、什么过滤条件、是否只挑涨过的 Mint？ | 榜单前列=稳定有优势 |
| 钱包内部交易风格 | 早期抢买、低频持仓、频繁翻转、跨币、加仓、分批出货，哪一类构成主要收益？ | “高胜率的钱包”是单一策略 |
| 条件化跟随 | 该钱包哪一种交易样式值得做纸上测试？为何放行某个市值/金额范围？ | 用历史赢家反向挑阈值就当预测 |
| 多钱包与资产角色 | 买入、转移、接收、卖出、提供资金、服务费角色可能不同吗？ | 转账=卖出，同源=同一人 |
| 实际跟随和回访 | 源钱包交易发生、信号显示、自己到场、最终结算有哪些差异？十天后还活跃吗？ | 作者成功截图=跟随账户净收益 |

## 按需用旧 Meme 知识解释“为什么”

如果某钱包把 Token 转给新钱包，可调用旧 Blix 的 Token Account/owner、swap/transfer、资产库存与多跳归因；如果某钱包只能首槽成功，可调用生命周期和执行经济学；如果一份盈利榜只包含历史大涨币，可调用样本选择与证据工程。**不需要先把这些一般知识全文学完才研究跟单。**
