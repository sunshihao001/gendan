# 跟单专属钱包判断卡｜具体行为而不是通用标签

## 先区分钱包的“实际用途”

| 钱包候选 | 要先验证的特征 | 目前最合理的去向 |
| --- | --- | --- |
| 首槽/秒级 sniper | Mint 创建后几秒买入、极短持仓、高执行费；我们何时才能看到？ | WATCH：发现线索，不直接把其历史入场复制为买点 |
| 低频持仓者 | 多币多周期、包含亏损、买卖和持仓时间可追溯 | PAPER-TEST：先按未来信号纸上复核 |
| 高频套利/机器人 | 高频成交、跨池交换、多币同步、可能依赖低延迟或资本规模 | SKIP 或仅机制观察 |
| 新钱包高胜率 | 地址年龄、有效样本、利润是否来自一次成功 Mint | UNKNOWN/WATCH，不能按百分比直接入选 |
| 执行与转仓地址 | A 买入、Token 到 B、B 卖出是否有真实交易签名？ | 网络调查而非复制 A 的所有买入 |
| 开发者/KOL 关联钱包 | 权限、资金来源、买卖/宣传时间及第三方服务的反证 | 发行侧调查/风险预警，不默认内幕同伙 |
| 被大规模复制的地址 | 跟随者的订单与源钱包卖出是否改变薄池价格？ | 跟单拥挤及退出流动性风险评估 |

## 每个候选都需要回答的八个问题

1. **它怎么入选的？** Froggy 哪次导出、按什么原始筛选、总样本有多少，是否只拿历史大涨币的赢家。
2. **它靠什么赚钱？** 盈利币数、失败币数、持仓成本、已经卖出的收入、未实现盈亏和费用；高 Win Rate 不自动有高净利润。
3. **它到底买在什么位置？** 交易 Slot、Mint 阶段、入场市值、金额与流动性；首槽/高速入场是否根本来不及复制。
4. **我们究竟复制哪个动作子集？** 把候选规则写成“在明确时间窗口内，只观察符合金额、市值、阶段和持仓约束的动作”，不能看完盈利再挑子集然后在同一历史里自证。
5. **它怎样退出？** 买入、分批卖出、重复买、Token 转仓、收币新钱包后卖出是不同动作，不能一律当“源钱包完成交易”。
6. **它是否属于一个网络？** 分别记录共同资金、相同交易执行程序、真实 Token 转移与经济权利；同槽/共享服务不可直接定同控。
7. **我们能否真正到场？** 源链上成交、供应商展示、观察者收到、可执行报价、最终成交是多种不同时间；考虑池深度、价差、费用、失败和退出。
8. **什么时候撤销判断？** 风格改变、长时间不活跃、失败样本增加、资金源解释变化、规则在新样本失效。

## 三类输出，避免给出假精确评分

- WATCH：能用于发现 Mint/转仓/卖出或风险，但未证明可跟。
- PAPER-TEST：一个具体“动作子集”可以事前冻结并在未来记录所有成功、失败、无报价及成本。
- SKIP / PAUSE：资料太缺、主要优势在不可复制时段，或风险/执行条件明显与观察者不符。
- UNKNOWN：重要证据拿不到。不能把 UNKNOWN 自动算 PASS。

## 研究卡格式（复制到任意笔记或 issue）

**对象**：wallet、Mint、观察时窗、Froggy 来源与导出版本。

**第一轮观察**：钱包年龄、交易总数、盈利/亏损分布、单币买卖结构、首槽比例、入场金额/市值、持仓和转仓。

**候选行为规则**：明确要观察哪类动作、排除哪类动作、理由与事前冻结时间；不写空泛“高胜率”。

**关系图证据**：签名→Token Account/owner/Pool→资金与 Token 边→潜在接收卖出地址；公共 Hub 单独标注，允许同控 UNKNOWN。

**跟随者经济账本**：T_chain、T_seen、T_decision、T_quote、可成交规模/价格、买卖费用、执行失败与退出时点。

**结论与反证**：WATCH/PAPER-TEST/SKIP/UNKNOWN；目前最可能的竞争解释；什么新事实会改变判断；下次复审日期。

## 示例：A 买入、B 接收、B 卖出

如果 A 买了 Mint-X 并转 Token 给 B，随后 B 在池中卖出：只能认定三个分别可观察的动作，不自动断定 A/B 是同一人或 A 取得了 B 的卖出收入。对“跟不跟 A”的具体含义：A 的公开买入可能只是派发链的早期步骤，不是值得复制的买点。要由时间、资产和后续风险证据决定是 WATCH 还是 PAPER-TEST。
